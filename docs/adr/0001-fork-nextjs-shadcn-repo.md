# Fork a separate Next.js/shadcn repo instead of rewriting the Nuxt app in place

The sibling repo (`ragdrien`) already has an ADR (0001) explicitly choosing to keep its Nuxt/Vue/Nuxt-UI scaffold rather than switch to Next.js, since the scaffold and its chat UI were already working. This repo does the opposite of that call — a full Next.js/React port, with shadcn/ui and Vercel AI Elements standing in for Nuxt UI's chat components — but does so as a **second, independent repo** rather than migrating `ragdrien` itself.

We chose this over rewriting `ragdrien` in place because the two repos serve different purposes: `ragdrien` remains the working, deployed Nuxt implementation, while this repo exists to explore the same product (a chatbot grounded in the owner's documents) on a React/shadcn stack, without putting the working app at risk mid-migration or forcing a decision between the two frameworks before the React version has proven itself. The trade-off is duplicated logic and features that must be kept in sync by hand (there is no shared package between the two repos): every change to the chat/RAG behavior in one repo is a manual port to the other, evidenced by this repo's own `CONTEXT.md` and RAG pipeline being line-for-line ports of `ragdrien`'s.
