# tabmania

A Visual Studio Code extension that provides code autocompletion similar to GitHub Copilot, but powered entirely by locally hosted LLMs (such as Mistral or Phi3) downloaded and served via Ollama — pressing Tab accepts the suggestion.

## Technologies

- TypeScript
- VS Code Extension API
- LangChain.js
- Ollama (local LLMs)
- esbuild
