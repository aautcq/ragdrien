# html-to-pdf-resume

An HTML/CSS resume template, sharable as-is and responsive, together with a JS build script that generates a PDF version of it — an earlier counterpart to `web-resume`.

## Technologies

- HTML5
- CSS3
- JavaScript
- pdfize (for the PDF build step)
