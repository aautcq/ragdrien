# nuxt-iconify-fontawesome

A package (`@aautcq/nuxt-iconify-fontawesome`) that converts Font Awesome icon collections (brands/regular/solid) into Iconify JSON data, so they can be used with popular Nuxt modules such as Nuxt Icon or NuxtUI through a `getIconSubSet` function. A companion/sibling project to `svg-to-iconify`, built on the same Iconify-tools foundation.

## Technologies

- TypeScript
- Iconify tools
- Font Awesome icon sets
