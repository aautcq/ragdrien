# swarm-shape

A library that renders a Canvas 2D path (any `Path2D`) made out of an animated swarm of particles, with configurable particle generation modes (sides/evenly/inside), size, count, color, and physics (noise, drift, repulsion).

## Technologies

- TypeScript
- Canvas 2D API
