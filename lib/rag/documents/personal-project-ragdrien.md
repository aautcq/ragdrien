# ragdrien

A personal chatbot: visitors converse with a locally-running LLM about the site owner, with replies grounded in the owner's own documents via Retrieval-Augmented Generation (RAG) whenever retrieval finds relevant content. This is the Next.js/React/shadcn sibling of an earlier Nuxt/Vue implementation, kept feature-identical. It's also the very project this document is part of.

## Technologies

- Next.js
- React
- TypeScript
- LangChain.js
- Ollama (local LLM + embeddings)
- SQLite
- Tailwind CSS
- shadcn/ui
- Vitest
