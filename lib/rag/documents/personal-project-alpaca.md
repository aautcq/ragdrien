# alpaca

A personal LLM chat UI (internally named "Matey"), built with Nuxt 3 and LangChain, that communicates with a locally running Ollama server to generate responses. Packaged with Electron into a cross-platform desktop app.

## Technologies

- Nuxt 3
- Electron
- LangChain.js
- Ollama (local LLM)
- Sass
