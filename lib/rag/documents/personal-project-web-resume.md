# web-resume

A sharable, responsive HTML/CSS resume template, built using Web Components (Custom Elements), along with a JS script that builds a PDF version of it.

## Technologies

- HTML5
- CSS3
- Custom Elements (Web Components)
- JavaScript
- pdfize (for the PDF build step)
