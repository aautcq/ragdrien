# svg-to-iconify

A CLI tool (`@aautcq/svg-to-iconify`) that converts a folder of SVG icon files into Iconify JSON icon-set data, enabling their use with popular Nuxt modules such as Nuxt Icon or NuxtUI. Configurable author, prefix, source folder, and output folder.

## Technologies

- Node.js
- TypeScript
- Iconify tools
- Yargs (CLI argument parsing)
- Chalk
