# vue-web-extensions-starter-pack

A starter pack for a Google Chrome extension running on Manifest V3, with its popup UI built using Vue.js 3.2 — a ready-to-clone base for building browser extensions with a modern Vue front end.

## Technologies

- Vue 3
- Vuex
- Vee-Validate
- Webpack
- Chrome Extension Manifest V3
