# pictacular

A progressive web app built with Nuxt/Nitro, designed to display and manage images stored in your own AWS S3 bucket — an awesome image gallery app you fully own the storage for.

## Technologies

- Nuxt
- Nuxt UI
- Prisma
- PostgreSQL
- AWS SDK (S3)
- WebAuthn (passkey login, via SimpleWebAuthn)
- Playwright (e2e tests)
- TypeScript
