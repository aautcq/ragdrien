# vue3-ts-boilerplate

A boilerplate Vue 3 application wiring together a batch of commonly needed tooling (routing, state, i18n, HTTP, styling, linting, testing) as a ready-to-clone starting point for new projects.

## Technologies

- Vue 3
- Vite
- Pinia
- Vue Router
- Vue I18n
- Axios
- Sass
- Jest
- ESLint / Prettier
